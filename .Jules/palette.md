## 2026-07-25 - [A11y & Micro-UX Integration]
**Learning:** Nested interactive elements (e.g., `<button>` inside an anchor `<a>` tag) are invalid HTML and result in poor screen reader / keyboard focus flow. Converting nested buttons to visually matching, non-interactive layout containers like `<span>` with customized high-contrast focus rings on parent links restores complete keyboard operability without layout shift. Additionally, including pre-filled custom message parameters in target WhatsApp external triggers bridges onboarding seamlessly.
**Action:** When implementing pricing cards styled as links, avoid nesting interactive tags inside anchors, ensure correct use of `target="_blank"` and `rel="noopener noreferrer"`, use semantic classes like `price-btn` mapped to unindented compact styles, and pre-fill contextual parameters to streamline lead attribution.
