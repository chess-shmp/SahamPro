## 2026-08-09 - [Nesting Interactive Elements & WhatsApp CTR Optimization]
**Learning:** Nesting interactive HTML elements like `<button>` inside anchor `<a>` tags causes major HTML validation issues and disrupts keyboard navigation flow because screen readers read conflicting interactive roles. Replacing these nested elements with semantic `<span>` tags styled as buttons restores validation and ensures smooth interactions. Additionally, prepopulating custom pre-filled WhatsApp queries (e.g., specifying package-specific messages) creates higher conversion intent (CTR) and establishes clear expectations on the landing page.
**Action:** Always replace inner button tags with block-level styled spans inside anchor wraps to keep markup clean and valid, and add descriptive pre-filled text to app-specific contact links.
