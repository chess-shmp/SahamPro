## 2026-06-08 - [HTML Validity & Interactive Nesting]
**Learning:** Interactive elements like `<button>` must not be nested inside `<a>` tags. This breaks HTML5 specifications and can cause inconsistent behavior across screen readers and browsers.
**Action:** Use a `<span>` or `<div>` styled as a button inside the `<a>` tag to maintain visual design while ensuring semantic validity and accessibility.

## 2026-06-08 - [WhatsApp CTA Friction]
**Learning:** Default WhatsApp links (`wa.me/number`) force users to type their own introductory message, increasing friction.
**Action:** Use pre-filled messages (via `?text=...`) to set context and make it easier for users to start a conversation, improving conversion rates for CTAs.
