## 2026-08-06 - Semantic Interactive Nesting & WhatsApp Message Pre-filling
**Learning:** Interactive HTML components, such as `<button>`, must never be nested inside focusable containers like `<a>` tags. Doing so creates invalid HTML and breaks keyboard focus flow and screen reader parsing. Interactive elements should be replaced with display block `<span>` tags with `cursor: pointer` styling inside the parent anchor link to preserve correct visuals while keeping markup standard-compliant. Additionally, pre-filling external messages (like WhatsApp query texts) using URL encoding minimizes input friction for potential customers, clarifying user expectations and improving conversions.
**Action:** Always refactor any nested button-inside-anchor anti-patterns using custom span block elements and cursor pointer styling. Ensure external WhatsApp/messaging contact CTAs are pre-filled with professional, context-specific text templates, and carry secure `target="_blank" rel="noopener noreferrer"` controls.
