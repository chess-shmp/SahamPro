# Palette's Journal - Saham Pro

## 2026-07-29 - Interactive Elements Nesting & WA CTA Optimization
**Learning:** Nested interactive elements like `<button>` inside `<a>` links are semantic violations that disrupt screen reader parsing and keyboard focus behaviors. Pre-filling messaging templates in WhatsApp links reduces conversion friction significantly.
**Action:** Replace nested `<button>` inside card links with layout-styled `<span>` blocks to maintain clickability and valid HTML. Add `target="_blank" rel="noopener noreferrer"` alongside pre-filled messages on all outbound messaging CTAs.
