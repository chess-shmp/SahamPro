# Palette UX Journal

## 2026-08-13 - Nesting Buttons Inside Links & WhatsApp CTA Optimization
**Learning:** Nesting interactive HTML elements like `<button>` inside `<a>` tags violates semantic HTML standards, resulting in broken screen reader navigation and keyboard traps. Additionally, hardcoded or blank WhatsApp redirection lacks personal touch, increasing customer drop-off.
**Action:** Replace nested `<button>` elements with `<span>` styled as buttons when nested inside anchors, and attach clear pre-filled queries matching the corresponding tier (Basic, Pro, Sultan) on external WhatsApp redirect CTA buttons to streamline customer engagement.
