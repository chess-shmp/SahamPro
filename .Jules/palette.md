## 2026-06-18 - Membership Card Accessibility and WhatsApp UX
**Learning:** Nesting interactive elements like `<button>` inside an `<a>` tag is invalid HTML and causes issues with screen readers and focus management. For complex cards that act as a single link, it is better to use a `<span>` or `<div>` styled as a button. Additionally, pre-filling WhatsApp messages via URL parameters (`?text=...`) significantly reduces friction for users by setting a clear context for the conversation. Applying `aria-label` to a container link that surrounds informative content (like a pricing card) can cause screen readers to suppress the internal text, making the details inaccessible.
**Action:** Always verify HTML validity when creating interactive cards. Use pre-filled messages for WhatsApp CTAs. Avoid using `aria-label` on informative container links; rely on internal content for the accessible name instead. Ensure workspace hygiene by removing temporary artifacts (logs, scripts) before submission.
