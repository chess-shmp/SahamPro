## 2026-07-05 - Avoiding Nested Interactive Elements for Accessibility
**Learning:** Nesting interactive elements like `<button>` inside `<a>` tags is invalid HTML and creates significant accessibility barriers. It can lead to unpredictable behavior in screen readers and "click hijacking" where events don't propagate as expected. Additionally, applying `aria-label` to a container element (like a card link) replaces the entire text content of its children for assistive technologies, potentially hiding critical information like feature lists.
**Action:** Use styled `<span>` elements instead of `<button>` tags when a call-to-action is nested within a parent anchor. Avoid using `aria-label` on complex containers unless the intent is to completely replace the accessible name with a simplified summary; otherwise, rely on the natural document outline and semantic children.
