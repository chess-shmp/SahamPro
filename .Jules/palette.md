## 2026-06-10 - Membership Section Optimization
**Learning:** Nested interactive elements (like `<button>` inside `<a>`) break accessibility and are invalid HTML. Using a styled `<span>` or `<div>` within the anchor preserves the visual design while maintaining a valid accessibility tree. Additionally, pre-filling messaging apps (like WhatsApp) via URL parameters reduces user friction and sets clear expectations.
**Action:** Avoid nesting `<button>` or `<input>` inside `<a>`. Use URL parameters (like `?text=...`) for messaging CTAs to improve conversion and UX.
