## 2026-06-14 - Membership UX and Accessibility Improvements
**Learning:** Nesting interactive elements like <button> inside <a> is invalid HTML and can cause unpredictable behavior for screen readers and keyboard navigation. Using a styled <span> instead maintains the visual design while ensuring semantic correctness.
**Action:** Always verify that interactive components do not contain other interactive elements. Use non-interactive tags like <span> or <div> for visual button elements nested within links.

**Learning:** Pre-filling WhatsApp messages via URL parameters (?text=...) significantly reduces friction by setting clear expectations and saving the user from typing the initial greeting.
**Action:** Use contextual pre-filled messages for WhatsApp CTAs based on the specific product or plan the user is interested in.
