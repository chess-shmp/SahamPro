## 2026-07-18 - Nested Interactive Elements and Customized WhatsApp CTAs
**Learning:** Nesting a `<button>` tag inside an anchor `<a>` tag violates semantic HTML validation and disrupts assistive technology. Screen readers can become confused as to which focusable target is active, and the keyboard tab order may trigger redundant or incorrect actions. To resolve this without altering visual design, refactoring the button into a semantic styling element like `<span>` with block display and text-align properties is highly effective. Furthermore, external WhatsApp CTA links are highly friction-sensitive; appending structured, personalized Indonesian text parameters tailored to the specific context (such as the membership tiers: Basic, Pro, and Sultan) dramatically reduces cognitive load and sets clear user intent upon redirection.
**Action:** Always verify semantic nesting during accessibility reviews, refactoring interactive elements into styled non-interactive tags where appropriate when wrapped inside cards. Always pre-fill third-party communication parameters with clean, tailored, localized text to optimize UX.
