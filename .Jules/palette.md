## 2026-07-27 - Restructured Nested Anchor Buttons and Enhanced Keyboard Focus for Saham Pro Landing Page
**Learning:** Found that nesting interactive `<button>` elements within `<a class="price-card">` components violates basic HTML specs and degrades accessibility, causing screen reader issues and unexpected browser behaviors. Additionally, identified that the landing page lacked high-contrast focus states and external target/rel attributes on contact links, impacting both navigation flow and session protection.
**Action:** Replaced the nested `<button>` tags with generic semantic `<span class="price-btn">` components styled like buttons via compact css `display:block;text-align:center;cursor:pointer;`. Added high-contrast keyboard navigation focus states through unindented `:focus-visible` styles with offset spacing, and improved external session flows with `target="_blank"` and `rel="noopener noreferrer"` parameters on pre-filled WhatsApp action buttons.
