# Palette's Journal

## 2026-07-14 - Interactive Element Nesting and Focus Visibility
**Learning:** Nesting `<button>` inside `<a>` is an accessibility violation that confuses screen readers and breaks HTML semantics. Additionally, a lack of `:focus-visible` styles makes the site difficult to navigate via keyboard.
**Action:** Replace nested buttons with styled `<span>` elements and implement high-contrast focus indicators for all interactive elements.
